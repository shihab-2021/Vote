# বাংলাদেশ ভোটার তালিকা PDF এক্সট্র্যাক্টর

এই টুলটি বাংলাদেশ নির্বাচন কমিশনের ভোটার তালিকার PDF ফাইল থেকে ভোটারদের তথ্য (নাম, ভোটার নং, পিতা/মাতার নাম, ঠিকানা ইত্যাদি) বের করে একটি Excel ফাইলে সাজিয়ে দেয়।

## 🖥️ ওয়েব অ্যাপ (সবচেয়ে সহজ পদ্ধতি) — PDF বাছাই, কনভার্সন প্রগ্রেস, ডেটা ব্রাউজ ও এডিট, সব একজায়গায়

`অ্যাপ_চালু.bat` ফাইলে ডাবল-ক্লিক করুন। এটি প্রয়োজনীয় লাইব্রেরি ইনস্টল করে একটি লোকাল সার্ভার চালু করবে এবং ব্রাউজারে `http://127.0.0.1:8765` খুলবে। অ্যাপে দুটি ট্যাব থাকবে:

- **কনভার্ট** — ফোল্ডার ব্রাউজ করে একটি PDF বাছাই করুন, "কনভার্ট শুরু করুন" চাপুন। পেজ/সেল/সংগৃহীত ভোটার সংখ্যা/সময় — সব লাইভ দেখা যাবে (আগের মতো ১-২ ঘণ্টা চুপচাপ অপেক্ষা করতে হবে না)। শেষ হলে সরাসরি "ডেটা দেখুন ও এডিট করুন" বাটনে ক্লিক করলেই পরের ট্যাবে ডেটা লোড হয়ে যাবে।
- **ডেটা ব্রাউজ ও এডিট** — আগে কনভার্ট করা যেকোনো Excel ফাইল বাছাই করুন। নাম/ভোটার নং/পিতা/মাতা/ঠিকানা দিয়ে সার্চ করুন, ওয়ার্ড অনুযায়ী ফিল্টার করুন, শুধু "যাচাই প্রয়োজন" সারি দেখুন। যেকোনো সেলে ক্লিক করে সরাসরি এডিট করা যাবে — এডিট করলে সংশ্লিষ্ট সারির লাল-চিহ্ন (যাচাই প্রয়োজন) স্বয়ংক্রিয়ভাবে পুনর্মূল্যায়ন হয়। "সেভ করুন" চাপলে পরিবর্তন সরাসরি একই Excel ফাইলে সেভ হয়ে যায়।

এই অ্যাপটি ভেতরে `voter_extractor.py`-কেই ব্যবহার করে, তাই কমান্ড লাইন/`চালান.bat`-এর মতোই ফলাফল একই হবে — শুধু ব্যবহার সহজ হয়েছে। বর্তমানে একবারে একটি PDF কনভার্ট করা যায় (একসাথে অনেকগুলো/পুরো ফোল্ডার ব্যাচ করার সাপোর্ট এখনো নেই — সেজন্য নিচের কমান্ড লাইন পদ্ধতি ব্যবহার করুন)।

## কমান্ড লাইন পদ্ধতি (একসাথে অনেক PDF / পুরো ফোল্ডার প্রসেস করতে)

### পদ্ধতি ১ — `চালান.bat` ডাবল-ক্লিক করুন (সহজ)

1. `চালান.bat` ফাইলে ডাবল-ক্লিক করুন।
2. প্রথমবার প্রয়োজনীয় লাইব্রেরি (pdfplumber, openpyxl, pymupdf, easyocr, ইত্যাদি) ইনস্টল হবে — **ইন্টারনেট সংযোগ লাগবে এবং প্রায় ১ জিবি ডাউনলোড হবে, কয়েক মিনিট সময় নিতে পারে।** পরের বার আর ডাউনলোড লাগবে না।
3. এরপর জিজ্ঞেস করবে:
   ```
   📁 ডিফল্ট ফোল্ডার: F:\
   অন্য ফোল্ডার পাথ দিন (খালি = ডিফল্ট):
   ```
   এখানে যেকোনো একটি লিখুন:
   - **একটি PDF ফাইলের সম্পূর্ণ পাথ** — শুধু ওই একটি ফাইল প্রসেস হবে।
     ```
     D:\Programming\JamalSir\চট্টগ্রাম-৬\চট্রগ্রাম-৬\RAOZAN\BAGOAN\151592\151592_com_1266_female_without_photo_71_2025-11-24.pdf
     ```
   - **একটি ফোল্ডারের পাথ** — এর ভেতরের (সাব-ফোল্ডারসহ) সব PDF একসাথে প্রসেস হবে।
     ```
     D:\Programming\JamalSir\চট্টগ্রাম-৬
     ```
   - খালি রেখে Enter দিলে ডিফল্ট `F:\` পুরো ড্রাইভ স্ক্যান হবে (সাধারণত এড়িয়ে চলুন)।
4. Enter চাপুন — প্রসেসিং শুরু হবে।

### পদ্ধতি ২ — কমান্ড লাইন থেকে

```
python voter_extractor.py "D:\Programming\JamalSir\চট্টগ্রাম-৬"
```
পাথ হিসেবে একটি PDF ফাইল বা ফোল্ডার — দুটোই চলবে।

## আউটপুট কোথায় পাবেন

ফলাফল সবসময় **ডেস্কটপে (Desktop)** সেভ হয়, ফাইলের নাম হবে:
```
voter_data_YYYYMMDD_HHMMSS.xlsx
```
(যেমন `voter_data_20260919_223000.xlsx`)

ভোটার সংখ্যা ৫ লাখের বেশি হলে স্বয়ংক্রিয়ভাবে একাধিক ফাইলে ভাগ হয়ে যাবে (`_part1.xlsx`, `_part2.xlsx`, ...)। সেভ লোকেশন বদলাতে চাইলে `voter_extractor.py` ফাইলের উপরের দিকে `OUTPUT_DIR` লাইনটি পরিবর্তন করুন।

## Excel ফাইলে কী থাকবে

- প্রতিটি ভোটারের: ক্রমিক নং, নাম, ভোটার নং, পিতার নাম, মাতার নাম, পেশা, জন্ম তারিখ, লিঙ্গ, জেলা/উপজেলা/ইউনিয়ন/ওয়ার্ড/এলাকা তথ্য, ঠিকানা।
- **"যাচাই প্রয়োজন" কলাম (সবার ডানে)** — কোনো রেকর্ডে তথ্য অসম্পূর্ণ বা সন্দেহজনক মনে হলে এখানে কারণ লেখা থাকবে এবং পুরো সারি **লাল রঙে** হাইলাইট হয়ে যাবে। এই সারিগুলো PDF-এর সাথে মিলিয়ে ম্যানুয়ালি একবার চেক করে নেওয়া ভালো।
- **"সারসংক্ষেপ" শীট** — মোট ভোটার, মোট যাচাই-প্রয়োজন সংখ্যা, প্রসেসিং সময় ইত্যাদি পরিসংখ্যান।

এই Excel ফাইলটি উপরের **ওয়েব অ্যাপের "ডেটা ব্রাউজ ও এডিট" ট্যাব** থেকে খুলে সার্চ, ফিল্টার ও এডিট করা যাবে।

## গতি সম্পর্কে গুরুত্বপূর্ণ তথ্য

নাম/পিতা/মাতা/ঠিকানা পড়তে OCR ব্যবহার হয়, যা এই কম্পিউটারে (GPU ছাড়া) প্রতি ভোটারে প্রায় **৪ সেকেন্ড** সময় নেয়। তাই:
- একটি সাধারণ PDF (৭০-৮০ পেজ, ~১২০০ ভোটার) প্রসেস হতে **~৭৫-৮০ মিনিট** লাগে।
- পুরো চট্টগ্রাম-৬ ফোল্ডার (৩৬৩টি PDF) একসাথে চালালে **কয়েকদিন** লাগতে পারে।

তাই বড় ফোল্ডার একসাথে না চালিয়ে একটি একটি করে বা রাতে/অলস সময়ে ব্যাকগ্রাউন্ডে চালানো ভালো।

## সমস্যা হলে

- **"Python পাওয়া যায়নি"** — https://www.python.org/downloads/ থেকে ইনস্টল করুন, ইনস্টলের সময় "Add Python to PATH" টিক দিতে ভুলবেন না।
- **লাইব্রেরি ইনস্টল ব্যর্থ** — ইন্টারনেট সংযোগ চেক করুন, আবার চেষ্টা করুন।
- **কোনো ভোটার পাওয়া যায়নি** — PDF-এ টেক্সট লেয়ার/পেজ না থাকলে বা ফাইল করাপ্ট হলে এমন হতে পারে।
- প্রসেসিং মাঝপথে বন্ধ করলে (Ctrl+C) পরে আবার শুরু থেকে চালাতে হবে — checkpoint শুধু ক্র্যাশ থেকে ডেটা বাঁচানোর জন্য, রিজিউম করার জন্য নয়।
