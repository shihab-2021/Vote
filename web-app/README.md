# ভোটার তালিকা — হোস্টেড ওয়েব অ্যাপ

React + FastAPI + PostgreSQL দিয়ে বানানো একটা অ্যাপ: PDF থেকে ভোটার ডেটা কনভার্ট করা,
একটা আসল ডাটাবেজে সংরক্ষণ করা, এবং সার্চ/ফিল্টার/এডিট/কাস্টম-ফিল্ড/এক্সপোর্ট — সব একই
React অ্যাপ থেকে, ব্রাউজারে, একাধিক মানুষ ব্যবহার করতে পারবে।

**PDF কনভার্সন (OCR) শুধু লোকাল ইনস্টলেশনে কাজ করে** — pdfplumber/pymupdf/easyocr-এর
মতো ভারী (~1GB) ML dependency এবং OCR-এর ধীরগতি (GPU ছাড়া প্রতি ভোটারে ~৪ সেকেন্ড)
বিবেচনায় হোস্টেড (Railway) সার্ভারে এগুলো ইনস্টল করা হয় না — আর যেহেতু PDF ফাইল সবসময়
আপনার নিজের মেশিনে থাকে, কনভার্সন রিমোট সার্ভারে চালানোরও কোনো ব্যবহারিক মানে নেই।

**গুরুত্বপূর্ণ:** এটা একটাই কোডবেস, দুইটা আলাদা প্রজেক্ট না। `app/ocr_engine.py`-এর ভারী
import (pdfplumber, pymupdf, easyocr) ঐচ্ছিক — ইনস্টল করা না থাকলে ব্যাকএন্ড স্বাভাবিকভাবেই
চালু হয়, শুধু "PDF কনভার্ট" পেজ/এন্ডপয়েন্ট নিষ্ক্রিয় থাকে। তাই:

- **লোকালি চালালে** (এই README-এর ধাপ অনুসরণ করে, OCR dependency-সহ ইনস্টল করলে) — React
  অ্যাপেই "PDF কনভার্ট" পেজ দেখা যাবে: ফোল্ডার ব্রাউজ করে PDF বাছাই, লাইভ প্রগ্রেস, এক্সট্র্যাক্ট
  করা ডেটার প্রিভিউ দেখা, এবং **আপনি "ডাটাবেজে যোগ করুন" চাপলে তবেই** ডেটা ডাটাবেজে যোগ হয়
  (Excel ব্যাকআপ সবসময় Desktop-এ সেভ হয়, ডাটাবেজে যোগ করুন বা না করুন)।
- **Railway/হোস্টেড ভার্সনে** — "PDF কনভার্ট" পেজে গেলে একটা স্পষ্ট বার্তা দেখাবে যে এই
  ফিচার এখানে নেই; বাকি সব (ব্রাউজ/এডিট/কাস্টম ফিল্ড/এক্সপোর্ট/Excel-ইমপোর্ট) স্বাভাবিকভাবে
  কাজ করবে।

`vote-2` ফোল্ডারের পুরনো স্বতন্ত্র (standalone) কনভার্টার টুলটাও অক্ষত রাখা হয়েছে, ব্যাকআপ/
ফলব্যাক হিসেবে — কিন্তু এখন থেকে মূল ওয়ার্কফ্লো এই `web-app`-এই, একটা React UI-তে।

## প্রথমবার সেটআপ (একবার করলেই হবে)

### প্রয়োজনীয়তা
- Python 3.12+, Node 20+
- PostgreSQL (এই মেশিনে থাকলে ব্যবহার করুন, নাহলে `docker compose up -d` দিয়ে একটা তুলুন)

### ১. ডাটাবেজ
```
cd web-app
docker compose up -d          # অথবা আপনার নিজের Postgres-এ একটা "voters" ডাটাবেজ বানান
```

### ২. ব্যাকএন্ড — লাইব্রেরি ইনস্টল
```
cd web-app/backend
python -m venv .venv
.venv/Scripts/activate         # Windows
pip install -r requirements.txt

# PDF কনভার্সন ফিচার চাইলে (ঐচ্ছিক, ~1GB ডাউনলোড):
pip install -r requirements-ocr.txt

copy .env.example .env         # তারপর .env ফাইলে DATABASE_URL/JWT_SECRET ঠিক করুন
alembic upgrade head           # ডাটাবেজে টেবিল তৈরি করবে
```
প্রথমবার ব্যাকএন্ড চালু হলে `.env`-এ দেওয়া `ADMIN_BOOTSTRAP_USERNAME`/`ADMIN_BOOTSTRAP_PASSWORD`
দিয়ে একটা অ্যাডমিন ইউজার নিজে থেকেই তৈরি হয়ে যাবে (শুধু `users` টেবিল খালি থাকলে)।

### ৩. ফ্রন্টএন্ড — লাইব্রেরি ইনস্টল
```
cd web-app/frontend
npm install
```

## প্রতিদিন চালানো (দুইটা টার্মিনাল লাগবে — ব্যাকএন্ড ও ফ্রন্টএন্ড আলাদাভাবে, একসাথে চালু থাকতে হবে)

**টার্মিনাল ১ — ব্যাকএন্ড:**
```
cd web-app/backend
.venv/Scripts/activate          # Windows (আগে থেকে activate না থাকলে)
uvicorn app.main:app --reload --port 8000
```

**টার্মিনাল ২ — ফ্রন্টএন্ড:**
```
cd web-app/frontend
npm run dev
```

দুটোই চালু থাকা অবস্থায় ব্রাউজারে যান: **http://localhost:5173**
(ফ্রন্টএন্ড dev সার্ভার `/api`-এর সব রিকোয়েস্ট স্বয়ংক্রিয়ভাবে ব্যাকএন্ডের ৮০০০ পোর্টে পাঠিয়ে দেয়,
তাই আলাদা করে কোনো URL/CORS সেটিংস লাগে না।)

লগইন করুন `.env`-এ দেওয়া ইউজারনেম/পাসওয়ার্ড দিয়ে (ডিফল্ট: `admin` / `change-me-immediately`
— প্রথম লগইনের পরই এটা বদলে ফেলা ভালো)।

- `requirements-ocr.txt` ইনস্টল করা থাকলে সাইডবারে **"PDF কনভার্ট"** পেজ দেখা যাবে — PDF বাছাই
  করে কনভার্ট করুন, ফলাফলের প্রিভিউ দেখুন, তারপর "ডাটাবেজে যোগ করুন" চাপুন।
- অথবা **"ইমপোর্ট"** পেজ থেকে আগে থেকে কনভার্ট করা যেকোনো `.xlsx` আপলোড করুন।

বন্ধ করতে দুটো টার্মিনালেই `Ctrl+C` চাপুন।

## প্রোডাকশন ডিপ্লয় (Railway)

`backend/Dockerfile` মাল্টি-স্টেজ — প্রথমে `frontend/` বিল্ড করে, তারপর সেটা FastAPI-এর
সাথে একই সার্ভিসে সার্ভ করে। **ইচ্ছাকৃতভাবে শুধু `requirements.txt` ইনস্টল করে, `requirements-ocr.txt` না** —
তাই প্রোডাকশন ইমেজ হালকা থাকে এবং "PDF কনভার্ট" ফিচার হোস্টেড ভার্সনে স্বয়ংক্রিয়ভাবে নিষ্ক্রিয় থাকে।
বিল্ড কনটেক্সট `web-app/` (backend/ ফোল্ডার না) থেকে চালাতে হবে:

```
docker build -f backend/Dockerfile -t voter-app .
```

Railway-তে:
1. GitHub রিপো থেকে নতুন প্রজেক্ট বানান, **PostgreSQL** প্লাগইন যোগ করুন (এটা নিজে থেকেই
   `DATABASE_URL` সেট করে দেবে)
2. একটা নতুন সার্ভিস বানান যেটা `backend/Dockerfile` দিয়ে বিল্ড হবে (build context: repo root
   অথবা `web-app/`, Dockerfile path: `web-app/backend/Dockerfile`)
3. এনভায়রনমেন্ট ভ্যারিয়েবল সেট করুন: `DATABASE_URL` (Postgres প্লাগইন থেকে auto), `JWT_SECRET`
   (লম্বা random string), `COOKIE_SECURE=true`, `ADMIN_BOOTSTRAP_USERNAME`,
   `ADMIN_BOOTSTRAP_PASSWORD`
4. ডিপ্লয় — কন্টেইনার চালু হওয়ার সময় `alembic upgrade head` অটো চলবে (Dockerfile CMD-তে আছে)
5. Railway-এর দেওয়া HTTPS ডোমেইনে গিয়ে অ্যাডমিন হিসেবে লগইন করুন, Import পেজ থেকে ডেটা তুলুন

## গুরুত্বপূর্ণ

- এখানে সংরক্ষিত নাম/ঠিকানা/জন্ম তারিখ/ভোটার আইডি সবই সংবেদনশীল ব্যক্তিগত তথ্য (PII)।
  `JWT_SECRET` ও `ADMIN_BOOTSTRAP_PASSWORD` অবশ্যই প্রোডাকশনে শক্তিশালী/গোপন রাখুন,
  এবং `COOKIE_SECURE=true` ছাড়া প্রোডাকশনে ডিপ্লয় করবেন না।
- Excel ফাইল শুধু ব্যাকআপ/এক্সপোর্ট — ডাটাবেজ থেকেই সব তথ্যের মূল উৎস (source of truth)।
  একই ভোটার নং আবার ইমপোর্ট/কনভার্ট করে "ডাটাবেজে যোগ করুন" চাপলে সেই রেকর্ডের মূল ফিল্ড
  (নাম, ঠিকানা ইত্যাদি) নতুন ডেটা দিয়ে **ওভাররাইট** হয়ে যায় — শুধু কাস্টম ফিল্ডের
  (extra_fields) ডেটা কখনো মুছে যায় না। তাই কোনো রেকর্ড ম্যানুয়ালি ঠিক করার পর একই উৎস
  আবার কনভার্ট/ইমপোর্ট করলে সেই সংশোধনও মুছে যেতে পারে।
- `app/voter_rules.py` এবং `app/ocr_engine.py` — `vote-2/voter_extractor.py` থেকে পোর্ট
  করা কোড। ভ্যালিডেশন/এক্সট্রাকশন লজিক বদলালে দুই জায়গায় মিলিয়ে আপডেট করুন (অথবা ভবিষ্যতে
  vote-2-কে সম্পূর্ণ সরিয়ে শুধু এই একটা কোডবেস রাখার কথা ভাবা যেতে পারে)।

## সমস্যা হলে

- **"পোর্ট ৮০০০/৫১৭৩ ইতিমধ্যে ব্যবহৃত হচ্ছে"** — আগের কোনো ব্যাকএন্ড/ফ্রন্টএন্ড প্রসেস এখনো
  চলছে, সেটা বন্ধ করে আবার চেষ্টা করুন।
- **ফ্রন্টএন্ডে লগইন করলে "Network Error"** — ব্যাকএন্ড (টার্মিনাল ১) আসলেই চালু আছে কিনা
  চেক করুন; `http://localhost:8000/api/health` ব্রাউজারে খুলে `{"status":"ok"}` দেখা উচিত।
- **"অ্যাডমিন লগইন কাজ করছে না"** — `.env` ফাইলে `ADMIN_BOOTSTRAP_USERNAME`/`PASSWORD` বদলে
  থাকলে, কিন্তু `users` টেবিল আগে থেকেই খালি না থাকলে নতুন করে অ্যাডমিন তৈরি হবে না (এটা শুধু
  প্রথমবারই চলে)। প্রয়োজনে ডাটাবেজে সরাসরি `users` টেবিল খালি করে ব্যাকএন্ড রিস্টার্ট করুন।
